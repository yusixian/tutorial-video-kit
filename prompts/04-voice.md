# 配音和读音

## TTS 调研（先不动手）

```text
帮我调研适合这种中文教程旁白的 TTS，本地能跑的优先，云端也列几个做对照。看自然度、中英混读、多音字和术语能不能修、跨句一致性、改一句方不方便、能不能拿到时间戳、许可证能不能商用。估算全系列配一遍的费用和耗时。你先调研，我确认后再试听。
```

## 试听

```text
不要跑完整的，每个引擎先只出一个声线，念这 4 句关键句：<4 个句子 id>。做成一个试听页，同一句话所有引擎并排，统一响度，每句旁边写该听哪里。再估算一下在免费额度和限流下推荐哪几个、全系列大概消耗多少额度。
```

选中之后：

```text
就用 <引擎和声线>，安排合适的语气，挑一段更长的段落试试。
```

```text
一口气配完全集，并把生成过程写成脚本和 README，下次改完台词只重配改过的段落。先别装进 video，我试听确认后再装。
```

## 语气和语速

```text
整体情绪不要太激动，是比较平静的教程感觉；语速不用特别快。语气写一句全集共用的默认值，每个场景最多补一句很轻的提示。语速用后期统一调，不要太多。
```

## 读音

```text
<词> 念错了，应该念 <读法>。字幕不变，只改配音念法。先试几种写法放进真实台词里各录几次，给我对照页听，我选了再全局替换。
```

```text
想办法把听不准的术语读音都校准：先把全集出现的英文、日文、缩写术语列成表，我告诉你每个词怎么念；然后每个词试几种写法，用音素或听写给个客观分，再给我改前改后的对照页。
```

## 别用真人或角色声线

想要「像某个角色」的感觉时：

```text
不要克隆真人或角色的声音。用文字描述设计一个原创声线，描述只写声音本身（年龄感、音色、语气、语速），不写人名、角色名。
```
