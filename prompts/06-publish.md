# 发布

## 投稿文案

```text
我希望置顶评论是这样的格式，时间写成 00:00:43 这样能点击跳转：<贴一段参考视频的置顶评论>。简介也参考这个：<贴参考简介>。不用照抄，按我们的内容改。字数超过 B 站上限要在终端提醒。
```

## 标题

```text
帮我想一个更适合 B 站、更吸引眼球的标题。给我 3–4 个方向，说明每个方向的钩子是什么；不要用「最强」「第一」这类词，也别写死时长。
```

## 封面

```text
重做合集封面，目标是缩成推荐流小图时也抓眼：<产品名> 要作为大字，贴纸写 <卖点>，<角色> 的小表情填空白，别抢主图。4:3 和 16:9 都要，缩小后自己看一遍中间有没有大块空白。
```

## 资料包

```text
资料包不要 Markdown，做成 PDF 和 Excel：PDF 适合看，每组提示词配效果图；Excel 适合复制，每条提示词单独一格，能放图的地方放图，没意义的格子不要。要整段复制的长文本单独给一个 txt。
```

## 预告片

我们用的是网上流传很广的 showreel 提示词，改成介绍自己的产品：

```text
作为这个长教程的预告，我想先出几波小视频，进行简单的预告和预热……Make a dynamic motion graphics video that shows what an incredible motion designer you are, like it's your showreel for a résumé. go all out.

Make it a video to introduce <产品页链接>
Use actual product screenshot/logo/assets
Must have music and motion must match the music

Do it like a real professional production video, not like a demo or prototype.
```

跑起来之后，两句话能省很多时间：「你不用竞争了，直接挑一个你觉得最合适的就行」「没必要那么恐怖的审片」。
