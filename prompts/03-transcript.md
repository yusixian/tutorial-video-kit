# 逐字稿

## 建逐字稿

```text
把逐字稿和脚本告诉我在哪里改。我要一份带时间码的逐字稿：每句有编号、时间码和句子 id，每个场景标出负责画面的组件文件，每句配一张成片截图。我说「EP1 #12」或给句子 id，你就能改那一句；画面也一样。
```

## 飞书同步

```text
逐字稿同步一份到飞书，让我能在上面评论、直接改字，截图也放进去。我说「同步逐字稿」时，你先把评论和改字拉回来写进脚本，再重新配音、渲染，最后重建飞书文档。重建会清掉评论，所以一定先拉回再重建。
```

## 修改记录表

```text
断句、读音这类问题我想成批记。给我建一个飞书文档，里面一张表：集、时间、句子编号、原文、问题类型、希望改成、备注、处理结果，第一行填个示例。我记完把链接给你，你逐条改，改完回填处理结果。写表之前先读一遍，只替换表格那一节。
```

## 反馈怎么写

从逐字稿复制一行，后面写要求：

```text
- #18 01:45 <原句> ｜<句子 id> - 这一块说词改一改，实际上……
```

或者：

```text
EP3 ⑤ 的画面，左上角的标签和右边的白底重合了
合集 12:19 这个过场图不好看
```
