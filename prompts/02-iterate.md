# 改片

## 整体审稿

```text
你把全系列台词、各节时长和物料整体审一遍。问题分四类编号：A 事实错误或前后矛盾，B 口径和措辞，C 读音风险（只改配音念法，字幕不变），D 要我实机确认的。每条写句子 id、原句、问题、建议改法，最后给出你建议默认做哪些。先不要改文件。
```

回复可以很短：

```text
A1 删掉 A3 多讲一点 A5改 A6ok A7ok B1ok B3 OK C 你按感受改 D 我确认后告诉你
```

## 借鉴参考片

```text
<参考视频文件> 是我要参考的教程。请抽帧检查，告诉我哪些值得借鉴：提示词动效、过场、讲解节奏、比较自然的地方。视频比较长，可以先 1.25 倍速或者稀疏抽帧，省 token。结论带原片时间码和截图，再说我们这边怎么用。记得改一改，不能和它太像。
```

## 以线上页面为准

```text
<某个数字或说法> 我想核实一下。以线上页面为准，文档只作参考。浏览器只读：不点生成、不领奖励，改过的设置测完恢复。汇报时单独写一段「浏览器里我做了什么」，并把依据记进 research/。
```

## 选图、选素材

```text
先出一份候选清单，放在一个自包含的 HTML 里让我选：每张有大图、作者、原作链接，可以勾选、排序、写一句介绍、设停留帧数，选完导出 JSON 给你。作品完整显示，不裁切。
```

## 口径调整

```text
开头没必要多强调 <竞品>，简单提一嘴就行，口径改成各有千秋。你先分析，列出要改的每一处（现在 → 改成），以及要我拍板的问题，先不要动文件。
```

## 控制节奏

- 「先给我草稿，我确认后再重渲」
- 「合集先不急着渲，等我们都确定之后再渲整个合集」
- 「不用检查这么频繁」
- 「你不用竞争了，直接挑一个你觉得最合适的就行」
- 「没必要那么恐怖的审片」
