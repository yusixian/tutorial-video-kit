# 交接和并行

## 写交接

```text
handoff 一下：更新 HANDOFF.md，旧版先备份。结构是进展、拍板与约束、试过什么、当前状态、下一步。拍板与约束只写我点过头的决定；我没采纳的建议也写进去，以后不要再提。
```

## 换一个会话接着做

```text
你这波工作做完，就总结一段上下文，让我在别的 Agent 上继续。要能直接复制过去：工作区路径、先读哪几个文件、目标、已经确定的要求、已经完成的（写明不要重做）、别覆盖的并行改动、下一步。
```

## 开并行线

给新会话的第一句：

```text
我是同一个工作区里的 <这条线的名字>，只负责 <范围>，只写 <路径>。先读 HANDOFF.md 和 COORDINATION.md 最后几条。Remotion 渲染一次只跑一个，要渲染先和 <渲染统整会话> 打招呼；<某文件> 归它管，要改先通知它。
```

提醒并行的会话：

```text
另一个会话也在跑 <任务>，你们两个协商谁先谁后，并且要注意内存占用。
```

## 让它汇报

```text
现在什么进度？按已完成、进行中、没做、要我拍板的来写；要我看的东西给完整路径和时间点。
```
