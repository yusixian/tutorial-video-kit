# 发布清单（B 站）

投稿物料都从时间轴生成，改了台词重跑一次就同步：

```sh
cd video
pnpm publish-kit   # → publish/<ep>.md 和 publish/compilation.md
```

每个文件里有标题、简介、置顶评论、标签和发布前检查。链接、交流群、资料包、BGM 署名这些在 `video/scripts/kits.ts` 里配置，模板里是 `example.com` 占位，发布前换成自己的。

## 简介和置顶评论

- **章节时间码放置顶评论。** 时间写成 `00:00:43`，B 站评论里点时间能跳到对应位置。按小节分组，组名放在【】里，组之间空一行；只有一个场景、并且和小节同名的，直接写一行。
- **合集按集分组**，每组第一条就是这一集的开头。
- **简介分段**：开头一句「感谢观看」和本集概要，然后是资料下载、相关链接、交流群、BGM、素材。模板用【】做小标题，想换成 emoji 小标题（比如 📃资料包、🛜网站、💬交流群）改 `scripts/publish.ts` 的 `description` 就行。
- **字数**：脚本按简介 2000 字、评论 1000 字检查（2026-09 投稿页的限制），超了在终端报警。合集的置顶评论最容易超，精简分组名或把链接挪进简介。

## 标题

- 钩子放前面，搜索词（产品名、「教程」「入门」、型号、年份）都在标题里。推荐流卡片只显示前面二十几个字。
- 带推广链接的视频按商业内容处理，不用「最强」「第一」这类极限词。
- 标题和封面里别写死时长，换配音、加内容之后都会变。

## 封面

- 分集和合集各出 16:10、16:9、4:3 三个比例。B 站首页推荐位用 4:3，个人空间用 16:9，投稿时取消「双比例同步改动」分开传。
- 缩成信息流的小图再看一次：大字够不够大，中间有没有大块空白。空白可以用主图放大、模糊、压暗铺满背景。
- 角色贴纸别单独飘在空白里，让它和画面里的元素有关系（指着主图、靠着贴纸）。

## 资料包

- 国内传播用 PDF 和 Excel，别用 Markdown。PDF 适合看（提示词配效果图），Excel 适合复制（每条提示词单独一格）。
- Excel 里嵌图要按显示尺寸的 2–3 倍像素，不然 Retina 屏上发糊；太大了再压 JPEG 质量。
- 要整段复制的长文本（比如 skill）单独给一个纯文本文件，PDF 和 Excel 里复制容易丢换行。
- 网盘文件更新后要重新上传，分享链接可以不变。

## AI 标注

- 投稿页「创作声明」勾选「该视频使用人工智能合成技术」。
- 简介里写明配音是 AI 合成。
- 画面里用到的他人作品，标作者和来源，资料包里列原作链接。

## 发布前检查

- [ ] `pnpm delivery-check` 通过，成片是最新版
- [ ] 人从头看一遍、听一遍，手机横屏看两三分钟确认字能看清
- [ ] `publish/*.md` 里没有占位链接
- [ ] 封面两个比例分开上传
- [ ] 创作声明已勾选
- [ ] 资料包已上传，链接已填进简介
